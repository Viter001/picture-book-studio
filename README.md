# 交互叙事创作工具 · PICTURE-BOOK-STUDIO

基于已有绘本项目的经验，为用户与外部 AI agent 制作交互叙事作品提供可视化工具。用途可覆盖绘本、Galgame 等，绘本作为首个验证场景。

## 当前状态

已确认 Electron + React + 自有绘本模型路线。目前处于产品设计阶段，尚未实现功能。全局设计与 MVP 范围独立维护，长期方向不自动进入首版；MVP 设计 v0.7 已重新提炼为具体审阅方案，尚待用户确认。
