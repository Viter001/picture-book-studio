# 绘本开发工作软件：MVP 产品规划 v0.1

日期：2026-10-27。状态：待讨论的产品规划，不是已批准的设计或实施计划。
来源：[产品讨论草稿 v0.6](product-discussion-draft.md)及本次用户要求。六个产品方向已确认；以下版本划分、能力边界与验收标准为建议，尚待用户确认。

## 1. 产品定位

面向绘本创作者的可视化制作工具：用户可以自行导入素材、组织页面和页面之间的流程、配置音频与动画，并通过图层控制展示内容。
同时为外部 AI agent 提供工具接口，支持人和 AI 协作编辑。软件内部不内置 AI 助手。
首批目标用户建议以当前绘本项目创作者为主，先解决必须依赖 AI 才能添加页面和组织内容的问题。

## 2. MVP 的核心目标

用户无需修改代码，即可完成一部短绘本的基本制作：

新建项目 → 导入素材 → 添加和编排页面 → 配置图层、音频与动画 → 连接页面 → 预览 → 保存并再次打开。

外部 AI agent 可以读取项目并执行一组实际编辑操作，结果能被用户查看和继续编辑。
“保存”在 MVP 中指保存可继续编辑的工程；独立发布或导出最终阅读作品另列后续阶段。

## 3. 范围取舍

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 页面优先：只完成页面导入和连线 | 最快验证最初痛点，开发范围最小 | 不能验证音频、动画、图层与 AI 的协作方式 |
| 六方向各做基础能力（建议） | 能用一部短绘本验证完整制作流程，并尽早验证 AI 接口 | 首版比页面工具大，必须严格限制效果、轨道和格式范围 |

本规划按第二种方案拟定，尚未代表用户选定。MVP 的目标是每项基础能力可用，后续版本再增加深度。

## 4. MVP 功能范围（建议）

| 模块 | 首版可用能力 | 后续再扩展 |
| --- | --- | --- |
| 页面与流程 | 新增、删除、改名页面；节点对应页面；可视化连线；设置起始页；单一路线；提示断开的页面 | 多分支、条件跳转、对话选项 |
| 多媒体导入 | 用户选择图片、音频、视频文件导入素材库；查看素材类型、名称与预览；将图片或视频放入页面 | 批量转码、更多编码、复杂素材检索 |
| 图层 | 页面中的图片和视频作为独立图层；选择、命名、显示/隐藏、调整上下顺序；基本移动和缩放 | 分组、锁定、蒙版、复杂混合效果 |
| 音频 | 区分背景音频与人物音频；可关联人物名称；每页配置一条背景与一条人物音频，设置音量、试听和移除 | 多人物同时混音、波形剪辑、精确时间轴与自动对齐 |
| 动画与转场 | 两组效果列表；页面转场先做无效果、淡入淡出；页内先做无动画、淡入；可调时长和预览 | 更多进入/退出/强调/路径效果，组合动画与触发编排 |
| 外部 AI 接口 | 实际接通至少一个外部 agent；支持读取项目、导入素材、添加页面、连接页面、设置图层可见性及保存 | 逐步覆盖全部编辑操作、批量任务和更丰富的结果反馈 |
| 工程与预览 | 新建、手动保存、重新打开工程；预览单页或全流程；基本撤销/重做；素材随项目管理 | 自动恢复、历史版本、独立阅读包与发布 |

上述数量和效果清单是用于控制首版规模的建议，不是对已确认产品方向的删减。

## 5. 必须说清的基础行为（建议，待确认）

- 页面连接在 MVP 中只定义前后顺序，阅读时由用户翻页；暂不允许多条出线或循环。
- 页面内图片和视频可定位、缩放及调整图层顺序；MVP 不增加绘画、修图或视频剪辑工具。
- 图层隐藏暂建议同时影响编辑画布和播放预览，避免两者表现不一致；是否还需要“仅编辑时隐藏”后续确认。
- 音频暂以页面为单位：进入页面开始播放，离开页面停止；背景可循环，人物音频播完停止。跨页背景连续播放与人物台词分段留待讨论。
- 视频首版提供基本播放与暂停；预览时视频原声默认静音，避免与背景/人物音频冲突，是否允许开启原声后续细化。
- 动画暂固定为进入页面后执行，不引入点击触发、对话触发或时间轴。浏览器或系统要求用户先交互才能播放声音时，预览入口须明确启动播放。
- 导入素材复制到项目管理范围内，避免原文件移动后工程失效；不修改用户原素材。
- 界面和 AI 使用一致的编辑规则及同一份项目状态；AI 修改可见、可撤销。最小接口应包含明确的成功或失败结果，失败不留半成品修改。
- 人与 AI 同时编辑时，需要避免静默覆盖；具体采用串行操作还是版本校验，在技术设计中确定。

这些行为直接影响体验，必须在开发前讨论确定，不能当作用户已经批准。

## 6. 格式兼容与原项目复用

主流格式兼容是已确认目标。建议首批验证样本为 PNG/JPEG 图片、MP3/WAV 音频、MP4 视频（选定一组常用视频及音频编码）。这里只是候选测试集合，不是已验证兼容承诺。
具体支持格式、编码组合和尺寸限制须结合运行平台实测后公布；导入不支持或损坏的文件时应给出明确提示，并保持工程可用。

原项目 `E:/code saving/INTERACTIVE-NARRATIVE-SYSTEM/` 是复用来源。进入技术设计前，核对页面数据、素材、播放、音频与动画能力；仅复用适合编辑器的部分。尚未进行该项代码评估，不能承诺旧工程直接导入或无损往返。
建议 MVP 先建立新工程制作流程，并使用经确认的原绘本素材进行试用；旧工程迁移列入后续版本，除非用户将其确定为首版必需。

## 7. 从 MVP 开始的版本路径

| 阶段 | 目标 | 完成标志 |
| --- | --- | --- |
| MVP-1：可编辑工程 | 素材导入、页面、基本图层、保存重开；同步定义共用操作模型与 AI 工具边界 | 用户能创建多页工程，重开后素材和位置一致 |
| MVP-2：可播放绘本 | 页面连接、基础音频、动画、转场和预览 | 能按连接顺序播放，音画行为符合约定 |
| MVP-3：可协作试用 | 外部 agent 实际调用、撤销与失败处理、完整流程验收 | 人与 AI 能接续编辑同一工程，真实样本通过验收 |
| v0.2：提升制作效率 | 扩展效果与格式，完善音频组织、跨页播放和素材管理 | 结合 MVP 试用反馈选择需求，不预先全部承诺 |
| v0.3：交付与兼容 | 可分发阅读成果、已有项目导入；按需求考虑分支与交互 | 分别明确导出和迁移验收，不把保存工程等同于发布 |

三个 MVP 阶段合起来才是本规划的首版；完成 MVP-1 不能宣称整体 MVP 已完成。时间与人力尚未估算，须待范围和技术评估确定。

## 8. MVP 验收场景（建议）

准备一部 3—5 页短绘本样本，包含多张图片、一段视频、一段背景音频和一段人物音频。

1. 用户自行导入素材、创建页面并调整布局，全程不手动改代码。
2. 建立页面连接，设置起点，预览顺序与连线一致；断开页面得到提示。
3. 页面中至少两个图层可以独立显示/隐藏，顺序和位置正确，重新打开后保留。
4. 背景和人物音频能清楚区分、试听与调整音量，翻页行为符合最终确认的规则。
5. 视频可以预览播放；页面转场与页内淡入可以从列表选择，效果和时长生效。
6. 保存、关闭、重新打开后，素材、页面、连线、图层、音频和动画设置保持一致；移动原始素材不破坏已导入的工程。
7. 至少一个外部 AI agent 实际读取工程、添加页面并建立连接；用户在界面看到结果、继续编辑，能够撤销该编辑操作。
8. 不支持的媒体、失败的 AI 调用或编辑冲突得到明确反馈，不损坏已有项目。

以上为未来验收标准，本次只交付规划文档，均未执行功能验收。

## 9. 下一轮需确认的决策

优先确认首版采用“六方向各做基础能力”还是“页面优先”。随后逐项确认：

- 产品形态：本地桌面软件还是浏览器工具，以及工程的保存位置。
- 首版是否必须打开现有绘本工程，而非仅使用其素材和能力。
- 单一路线、每页基础音轨及最少动画效果能否满足首版试用。
- 图层可见性、音频翻页行为和视频原声的约定。
- 外部 AI 首个验证对象、调用方式与共享编辑规则。

此前“登录登出”一词含义仍未确定，不据此引入账号系统或已批准的音频进出场机制。
正式设计需在这些关键取舍确认后编写；本规划不指定技术栈，不授权开始功能实现。
