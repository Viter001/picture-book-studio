# MVP 设计 v0.7 · 实施基线

2026-10-28，依据 [全局设计 v0.3](product-roadmap.md)重新提炼。用户于 2026-10-28 表示“可以开工跑一版”，本稿范围及默认行为据此作为首版实施基线；功能验收仍待实际执行。全局方向不等于首版承诺。

## 1. 首版定位与成功标准

让作者在本地桌面工具中，不手改代码，制作一部有图片、文字、声音和简单选择路径的短互动绘本，能够预览、保存、关闭后继续编辑。外部 AI agent 能通过少量工具协助整理页面。

技术主路线已确认：Electron + React + 自有绘本模型。本稿建议先验收 Windows 桌面版；其他系统另行验证。产品长期可用于 Galgame 等作品，本版仅以短绘本验证核心制作流程。

建议交付：可启动的桌面应用包、5 页示例工程、简明制作说明及最小 agent 接入说明。工程可在本工具中打开和预览；不以独立网页或游戏发布包作为首版交付。

## 2. 方案取舍与本稿选择

| 方案 | 能得到什么 | 取舍 |
| --- | --- | --- |
| 页面与图片工具 | 最快验证手动导入和页面编排 | 音画表现和 AI 协作无法一起验证 |
| 基础互动绘本工具（本稿建议） | 图片文字、简单流程、基础音频/效果、最小 AI 接入形成完整样本 | 比纯页面工具多，但严格限制每项深度 |
| 全多媒体叙事工作台 | 视频、规则状态、多轨、发布等较完整能力 | 当前规则未确定，首版范围过大 |

用户已授权按第二种方案开工，以下为实施基线。视频等全局方向保留，在首版中明确延期。

## 3. 两个工作区与制作过程

### 流程工作区

以用户提出的 ComfyUI 式“卡片＋流程线”为参考。一张卡片对应一个页面，显示名称、缩略图、起始页标记及问题提示。支持新增、改名、删除、拖动卡片，画布平移/缩放与适应全图。

每页有一个接收连接的入口，可接受多条入线；出口为可命名的列表，每个出口连接一个目标页。用户新增出口，拖线到目标入口，或选中线修改名称/删除。支持多出线、汇合与回到其他已有页面；首版禁止直接连接自身，同一页可经其他页面形成循环。出口列表顺序决定预览按钮顺序。

双击卡片或点“编辑页面”进入页面工作区；“返回流程”恢复原流程视口并选中该卡片。首版只开一个页面编辑视图，不做多标签、章节折叠、复杂自动布局和小地图。

### 页面工作区

参考 PPTist/Penpot 的操作组织：左侧素材/图层列表，中间页面画布，右侧所选对象属性；顶部提供返回流程、撤销/重做、保存和预览。音频与页面转场作为页面属性分组；图层动画随图层选择显示。

支持空白页、添加图片、添加文字，拖动位置、调整大小、编辑名称/文本和显示状态、调整前后顺序。一次拖拽结束记录一次撤销，不把每个移动像素记成独立操作。

视觉建议先用中性浅色、一个强调色、清楚的边界和中文标签。具体色值、间距、图标和控件细节留给后续界面设计，未制作或批准视觉原型。

### 一个完整流程

新建工程 → 导入图片与音频 → 建立页面卡片 → 进入各页排版 → 设置声音及基础效果 → 连接出口 → 从起点预览 → 保存 → 关闭并重新打开。

## 4. 功能边界

| 模块 | 本稿纳入 | 明确延期 |
| --- | --- | --- |
| 工程 | 新建/打开/手动保存、未保存提示、版本与素材完整性检查 | 自动恢复、云同步、跨会话撤销历史 |
| 页面和图层 | 图片/纯文字、位置尺寸、命名、顺序、显示/隐藏、删除、基本撤销 | 富文本、绘画、蒙版、分组、锁定、旋转及复杂对齐 |
| 流程 | 起点、具名出口、分支、汇合、经其他页面回连 | 条件判断、隐藏数值、自动跳转、独立逻辑节点 |
| 音频 | 每页一条背景音频和一条人物配音；导入、替换、移除、试听、音量 | 多人物混音、波形剪辑、精确时间轴、跨页连续背景音 |
| 动画 | 图层“无/淡入”；页面转场“无/交叉淡化”；时长可调 | 移动路径、退出/强调、组合动画、点击和条件触发 |
| 预览 | 当前页或工程起点播放，按出口按钮前进，可随时退出 | 读者进度存档、剧情回滚、独立运行包 |
| 外部 AI | 一个实际宿主接入，读取/导入/添页/连线/显示设置/保存 | 全功能 agent 操作、无人值守批量创作、内置聊天 |
| 媒体 | 指定图片与音频组合，导入验证及失败提示 | 视频、GIF 动画、SVG、批量转码及全格式兼容 |

音轨限制是首版 UI 和行为限制，不要求永久固定模型只能两轨。操作到延期能力时明确提示，不显示未实现的可用按钮或输出虚假成功。

## 5. 基础行为建议

### 页面与图层

新建工程由作者填写名称和画布宽高，提供横向、纵向预设；首次保存后首版不提供全工程改尺寸。所有页共用工程尺寸。预览等比适配窗口，留白补足，不拉伸内容。

图片保留比例添加到页内，支持位置和宽高调整；文字支持纯文本、字号、颜色和基础对齐，不做富文本与字体文件嵌入。图片/文字是独立图层，隐藏同时影响编辑画布和预览，列表中仍可选中以恢复显示。可见图层按列表顺序叠放。

删除页面时展示受影响连接数量，确认后将该页及关联连接作为一次操作删除；可撤销恢复。删除起始页后工程无起点，提示重新指定，不暗中选另一页。删除图层不删除素材文件，首版不提供自动清理未使用素材，避免撤销失效。

### 流程播放

所有出口均由用户主动选择，暂不处理条件和自动跳转。一个出口显示“继续”或作者填写的名称；多个出口显示所有名称对应的按钮；没有出口显示“本次阅读结束”和“从头开始”。按钮由播放器固定区域呈现，不做页面内自由排版的选项组件。

点击出口只产生一次跳转，转场中临时禁用出口；跳转后重新播放目标页的音频和淡入。回连重新进入页面遵循同样规则，不计分、不积累隐藏状态。首版无“回退一步”剧情按钮，作者可退出并从当前页重新预览。

未连接到目标的出口允许作为草稿保存，并在卡片提示；播放到该页时列出不可用出口及原因，其他有效出口仍可使用。它不被当作已完成终点。无工程起点时禁用“从头预览”，但可预览选中的页面。不可达页面提示而不禁止草稿保存。

### 预览与编辑同时发生

本稿默认预览使用启动时的只读工程快照。预览期间 agent 可以继续编辑工程，编辑界面接收新 revision，但不改变已启动的播放内容；界面提示“工程已更新，重新预览后生效”。退出再进入预览使用最新版本。

启动快照引用的素材在预览结束前保持可读取；首版导入/替换使用新的素材引用，不覆盖仍被预览使用的文件，也不自动清理旧文件。人工切回编辑前退出当前预览，不同时维护多个播放器。这一规则已随 v0.7 作为实施基线。

### 音频与动画

进页后背景和配音同时开始，背景循环、配音播放一次；各自音量独立。离页停止并重置该页两条音频，退出预览停止全部声音。没有绑定音频则静默。编辑态试听同一时间只播一条，进入预览先停止试听。

淡入仅在进页时执行，所有可见图层可同时淡入；隐藏图层不执行。页面转场采用目标页配置；转场完成后启动目标页图层动画与声音，旧页声音在跳转开始时停止。时长建议范围 0.1—3 秒，无效果立即完成。离页和退出取消未结束动画。

这是刻意简单的首版演出规则；跨页音乐、人物逐句配音与时间轴不通过临时特例加入。

## 6. 素材与工程产物

图片目标为 PNG、JPEG、WebP 静态图；音频目标为 MP3、WAV（PCM）、M4A（AAC）。这些是待实现和测试的目标，不是已通过兼容性保证。实际锁定 Electron 版本后逐格式用样本验证；延期格式明确拒绝，不依靠扩展名假装兼容。

导入通过文件选择，可选择多个文件；逐个报告成功或失败。失败文件不创建素材记录，其他成功项保留。复制到工程 assets/，不修改原素材。元数据与预览只基于成功验证的文件，原路径不作为运行依赖。

建议工程目录包含 project.json、assets/ 和可重建缓存；新建时先选择工程位置。JSON 保存格式版本、工程/页面/图层/素材/出口的稳定 ID、当前已支持内容、流程布局等。使用项目相对路径；播放器不依赖开发服务器或临时外部文件。字体暂依赖目标系统，跨系统字形一致不作为首版承诺。

允许保存未完成流程；不可解析的内容不得覆盖有效文件。手动保存写入失败时保留上一份有效工程，未保存状态和失败原因可见；关闭或切换工程时提示保存/放弃/取消。缺失素材保留引用并显示占位及对象定位，不自动删除；允许替换为有效素材。

未知新格式版本或声明了未支持能力的工程拒绝编辑并提示原因，不将其降级保存。撤销针对本次打开期间的编辑命令，工程重新打开后不保留撤销栈。

## 7. 外部 AI 的最小验证

建议以一个用户实际使用、支持本地工具接入的 agent 宿主验证；默认先验证当前工作环境中的宿主，若不可用再明确改选，不要求用户现在指定所有未来 agent。

候选工具：project_get（含页面/素材/连接清单）、assets_import、pages_add、pages_connect、layers_set_visibility、project_save。pages_add 可接受名称和已导入的背景图片素材 ID，以便 AI 能创建有内容的页面；其余排版仍可人工完成。接口参数与返回值在实施计划前锁定。

命令经同一本地应用服务，读取与修改均限定当前打开的工程。使用 projectId、requestId、expectedRevision，返回新 revision 与稳定 ID；版本冲突不覆盖，重复请求不重复创建，修改通知界面并进入相同撤销栈。无工程、无效引用及未授权素材路径返回明确错误。

采用 MCP bridge 是本稿建议；接入成功必须以真实宿主调用为证据。首版只演示 agent 读取工程、导入一张图、创建页面、建立连接、修改图层可见性、保存，用户能看到并继续编辑；不承诺 agent 独立制作整部作品。

## 8. 实现边界与保留空间

Electron 主进程管理工程及文件，preload 暴露有限操作；React 负责界面与预览，共用核心负责类型、校验与命令。页面渲染与动画使用与全局路线一致的 Web 实现思路；React Flow、Moveable、TypeScript 等配套选择需在实施前锁定。

页面集合与连接集合独立，保留未来条件/效果演进的边界，但本版不创建变量系统；播放状态与作品定义分开，保留未来存档适配；工程内容不绑定 Electron API，保留导出壳替换空间。首版不创建完整插件系统或未使用的未来模块。

旧绘本提供素材和实现参考，不承诺直接导入其 story.js 或完整迁移已有作品；读取任意工程不执行其中的脚本。

## 9. 首版验收：一个 5 页样本

样本采用 P1→P2，P2 分别连接 P3/P4，P3→P2，P4→P5，P5 结束。它检验分支、回连与结束，所有出口均为普通按钮，不涉及隐藏条件。

| 编号 | 验收内容 |
| --- | --- |
| A1 | 普通作者通过界面创建 5 页、导入图片和文字排版，不手改代码 |
| A2 | 卡片与连线表达样本；进入页面再返回，流程视口和当前节点恢复 |
| A3 | 分别走通 P2→P3→P2 与 P2→P4→P5；按钮与目标匹配，转场重复点击不造成多次跳转 |
| A4 | 图层移动、改尺寸、排序、隐藏及恢复正确；删除页面的连接能随撤销恢复 |
| A5 | 背景与人物音频可区分、音量生效，离页/退出无残留声音，回连重新播放 |
| A6 | 两类基础效果可选择，时长生效，旧页/隐藏图层无残留动画 |
| A7 | 保存关闭重开后内容、素材和连线一致；移动原素材或复制整个工程到新目录后仍可打开 |
| A8 | 不支持/损坏文件、缺失素材、无起点、悬空出口、保存失败有明确结果，既有有效工程未受损 |
| A9 | 一个真实 agent 宿主完成第 7 节最小操作，界面同步，用户能继续编辑和撤销；请求重试与过期版本不损坏工程；播放中修改/删除页面不改变当前快照，重启预览后采用新版本 |
| A10 | Windows 实际打包应用可打开示例工程并完成流程；分别记录媒体样本结果及常见系统缩放下的界面检查 |

这是本版验收目标，当前实际结果见 docs/acceptance.md。A1—A10 全部通过才可声明正式完成；开发预览版的自动化结果不代替普通桌面人工验收，不能以协议模拟代替 A9。

## 10. 开发顺序与已确认取舍

建议实施顺序：工程/命令/最小 agent 通路验证 → 页面与图层 → 卡片流程及按钮播放 → 音频和效果 → 完整保存/失败/撤销与打包验收。前期贯通 agent 通路，避免最后才发现需要改写编辑核心。时间与工期尚未估算。

实施保留以下三项取舍：

1. 视频、隐藏数值和独立发布延期，首版交付工程与工具内预览。
2. 分支与回连纳入最小样本，但只做普通出口按钮，不做条件规则。
3. 六方向保留基础代表能力，外部 AI 只做一个宿主的最小接入。

其他具体行为按本稿默认方案实施，后续调整需同步记录。原词“登录登出”未被当作任何已批准机制。0.1.0 已进入开发预览，实施计划及实际验收单独维护。
