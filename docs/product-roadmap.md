## 1. 产品定位与决策状态

原始痛点是页面导入和内容组织依赖 AI，用户无法手动添加页面。工具让用户通过可视化方式自己制作，也为外部 AI agent 开放操作接口。

产品源于绘本，但使用者可能制作 Galgame 或其他交互叙事作品，可能发布网页、分发程序，或者由 agent 制作给主人游玩。最终用途保持开放；绘本是首个验证场景，不是产品能力上限。

| 状态 | 当前内容 |
| --- | --- |
| 用户已确定 | Electron + React + 自有绘本模型；外部 agent 接入，内部不内置 AI 助手；工具及其产物需规范 |
| 已提出的产品方向 | 页面与流程可视化、背景/人物音频管理、主流多媒体导入、类似 PPT 的动画与页面转场、图层显示控制 |
| 用户明确的全局约束 | 流程有分支和循环；复杂流程图与单页编辑常驻同屏拥挤；全局发展与 MVP 分开 |
| 设计建议，尚未逐项确认 | TypeScript 等配套组件、共用命令架构、双工作区导航、工程文件形式与运行包规则 |
| 探索方向 | 隐藏数值、条件选项、Galgame 专项能力及多目标导出细节 |

节点当前表示页面。“场景”只是未来抽象命名候选，不要求现在选定或重命名 UI。未由当前需求推导物理、3D、实时战斗等通用游戏引擎范围。

## 2. 功能方向与待细化行为

| 方向 | 已提出目标 | 仍需讨论 |
| --- | --- | --- |
| 页面管理 | 用户自行添加、导入和组织页面 | 原始页面输入形式、空白页、单页/批量导入、缩略图、改名、替换和删除 |
| 流程编排 | 页面节点及有向连接，支持非线性关系 | 起点/终点、分支触发、循环、删除节点后的连接处理；列表排序不默认等于播放顺序 |
| 多媒体导入 | 用户导入图片、音频、视频等主流素材 | 格式及编码清单、预览、失败反馈、素材复制或引用方式 |
| 图层 | 可以选择显示或隐藏图层 | 图层划分、顺序、文字、分组与锁定；显示控制作用于编辑还是播放 |
| 音频 | 管理轨道，区分背景与人物音频 | 轨道数量、人物关联、音量、进出页/暂停/重播、跨页连续播放、剪辑和同步 |
| 动画与转场 | 类似 PPT 的可选效果列表；页内动画与页面转场分开 | 作用对象、效果清单、时长/延迟/顺序/触发；进入、退出、强调、移动分类仍为建议 |
| 外部 AI 作者 | 外部 agent 可调用工具完成操作，内部不内置助手 | 协议、宿主、工具覆盖、结果可见与撤销、并发和授权边界 |
| 工程与预览 | 候选闭环为制作、预览、保存重开 | 手动/自动保存、当前页/起点预览、旧工程导入及独立导出版本归属 |

音频讨论中的用户原词“登录登出”含义尚未明确，不据此引入账户系统或确定音频进出场语义。对话、选项和动画触发细项后续讨论，宏观方向不代表所有细节获批。

建议动画预设定义效果 ID、名称、参数、默认值及适用对象，界面和 agent 共用定义，作品只保存 ID 和参数。转场作用于页面容器，页内动画作用于图层；离页应清理动画、计时器和相关媒体状态。播放调度统一管理进页、离页、暂停和重播，避免多个面板各自驱动一份声音。

## 3. 非线性流程与故事状态

### 3.1 连接结构与播放规则

建议页面和连接各用稳定 ID，连接表达 sourcePageId 与 targetPageId，允许多出线、汇合与回连。回到已有页面引用同一页面，不复制内容。流程图坐标与页面内坐标分开，边的名称/顺序仅用于辨认，不能擅自决定分支选择。

多个出口由选项、点击区域、条件还是事件触发，须单独确定。编辑态“选择本次预览路径”可帮助检查图，但不能代替最终阅读行为的验收。

循环本身合法；检查应关注无效引用、起点缺失、不可达页面，以及没有等待用户或媒体的连续自动循环。图遍历用 visited 等机制防止无限运行，路径播放可以重复进入页面，退出预览始终可用。

复杂图建议提供平移、缩放、小地图、搜索和当前节点邻接关系高亮；节点只展示缩略图、名称和必要状态。自动排版、章节折叠、路径筛选根据实际复杂度引入，不按无环图假设限制真实连接。

### 3.2 隐藏数值与条件选项（探索）

用户提出不同选项改变隐藏数值，影响重要节点可选的选项。候选能力为数值/布尔状态、选择效果及开放条件。变量含义、初值、范围、公式和规则编辑方式尚未确定。

需要讨论重复选择是否重复计分、回退是否回滚、重播动画是否触发效果、无可用出口如何处理、条件不满足时隐藏还是禁用选项。作者调试可显示当前状态、变化来源和未开放原因，而读者界面可以隐藏这些数值。以上是设计建议，不是已批准的规则或首版任务。

作品初始定义与读者运行状态分离；若采用这套体系，所有目标运行时使用相同条件和效果语义，不能网页、桌面分别维护一套剧情逻辑。

## 4. 工作区与视觉设计候选

| 组织方案 | 特征与取舍 |
| --- | --- |
| 双工作区（推荐） | 流程和单页各获得完整空间；双击节点进入页面，返回时恢复视口并定位节点；共用工程与撤销 |
| 流程加侧边抽屉 | 适合改名和少量属性；完整音画/图层编辑仍可能拥挤 |
| 多页面标签 | 适合频繁跨页比较，但增加标签和状态管理；可作为双工作区后续增强 |

用户尚未选定具体导航。建议单页编辑参考 PPTist/Penpot，按选择对象显示属性；预览是两个工作区共用能力，图层/音轨/动画围绕当前页组织。页面连接与页内对象各在适合的工作区编辑。

| 视觉方向 | 建议特征 | 取舍 |
| --- | --- | --- |
| 清晰桌面工具（推荐） | 中性浅灰、清晰边界、单一强调色 | 页面和文字操作易读，音轨仍需清楚区分 |
| 专业媒体工作台 | 深灰、突出预览和轨道、较高信息密度 | 音画工作集中，但基础操作易被面板挤占 |
| 轻量绘本工作室 | 柔和浅色、大缩略图、逐步展开操作 | 亲和，占用空间较多 |

建议以第一种为基线参考其他两者，不预建多套主题。视觉参考为 PPTist 的页面/动画操作、Penpot 的页面/图层/属性组织、DaVinci Resolve 的素材及轨道表达、React Flow 的流程浏览，官方链接见第 11 节。

必须考虑保存中/未保存、导入中、格式不支持、素材缺失、AI 修改与连接状态；界面使用页面、图层、背景音乐等业务词，不直接展示内部 schema 或 IPC 名称。外部 AI 可有连接及操作记录入口，但不增加内置聊天助手。尚未制作草图、确定颜色字号或实机操作这些参考产品。

## 5. 技术路线与原项目复用

### 5.1 已选路线及取舍依据

用户已选择 Electron + React + 自有绘本模型：方便衔接 Web 播放能力、本地素材和 Node 工具，代价是安装体积和桌面进程维护。Electron 不保证所有媒体格式可播放。

曾比较 Tauri（应用壳更轻，但系统 WebView 差异及 Rust/前端边界需验证）和直接二次开发 PPTist（现成编辑能力多，但需接受其架构与授权条件）。保留理由供回顾，不重新将技术主路线标为待选。

### 5.2 原绘本的定向调研事实

来源项目为 `E:/code saving/INTERACTIVE-NARRATIVE-SYSTEM/`。2026-10-27 已经 GraphFlow 和定向读取核对，未做完整移植评估或修改源项目代码。

| 已有能力 | 核对入口 | 可复用方向 |
| --- | --- | --- |
| 原生 HTML/CSS/JS，无 npm 依赖和构建 | README.md | 保留 Web 播放思路，编辑工具另建结构 |
| 页面、图层、音频、视频和出口数据 | ink/story.js:31 起 | 适配器映射到新模型，不能假定无损 |

## 6. 前后端、模型与 agent 接口（建议）

### 6.1 职责与候选代码边界

| 模块 | 职责 | 候选位置，尚未创建 |
| --- | --- | --- |
| React 前端 | 编辑交互、流程/页面视图、素材属性、临时选择/拖拽反馈 | apps/editor |
| Electron 主进程与 preload | 窗口、工程文件、白名单 IPC 与事件、本地连接 | apps/desktop |
| 共用核心与本地命令服务 | 类型、校验、工程状态、编辑命令、撤销、revision、迁移 | packages/project-core |
| 播放模块 | 页面渲染、音画生命周期、状态推进；编辑预览和运行包共用 | packages/player |
| agent bridge | 外部工具到同一命令服务的映射，不另写工程 | packages/agent-bridge |
| 旧工程适配 | 按字段映射与报告兼容性 | packages/legacy-import，按需再建 |

前端运行于 renderer，本地服务协调文件与工程写入。主进程处理轻量命令，耗时分析/转码放 worker 或 utility process；首版本地应用不依赖云端账号、远程数据库。先保持普通模块边界，无需提前部署复杂 monorepo 或插件平台。

### 6.2 数据与编辑一致性

候选类型为 Project（格式版本、ID、revision、起点、尺寸）、Asset（类型、相对路径与元数据）、Page、Layer、Connection、AudioTrack 和动画配置。页码作展示、稳定 ID 作引用；节点位置与图层位置分开，播放时间和界面选择不混入作品内容。具体 schema 不在本文冻结。

工程建议使用 JSON 加素材目录，导入复制原件，缓存/缩略图可重建。写入用临时文件与替换机制，Windows 下需验证失败不损坏旧工程。未完成的流程允许草稿保存，发布检查单独进行。

所有修改建议经过 AddPage、ConnectPages、ImportAsset、SetLayerVisibility、SetAudio、SetAnimation 等命令。携带 projectId、requestId、expectedRevision；按顺序校验并提交，返回新 revision、对象 ID、撤销信息和变更事件。重复请求不重复创建，过期版本不覆盖新修改。拖拽临时反馈在结束时合并成一次命令；图层定位与内部动画分层，避免同时覆盖 transform。

### 6.3 外部 agent 通路

用户界面 → preload/IPC → 本地命令服务；外部 agent → MCP 工具进程 → 本地 IPC → 同一本地命令服务。服务是工程单一写入者，bridge 不直接修改 project.json。

建议 MCP stdio 由 agent 宿主启动桥接进程，连接正在运行的应用；Windows 命名管道和其他平台本地域套接字为候选。工具例子为 project_get、assets_import、pages_add、pages_connect、layers_set_visibility、project_save，具体集合和协议仍待定。

返回结构化错误及稳定 ID；未打开工程、版本冲突或无效路径明确失败，不隐式产生另一工程写入者。素材路径限于用户选择或授权范围，本地连接校验会话与工程，renderer 不取得任意 Node 文件操作权限。某个模型不等于某个宿主支持 MCP，实际接入需逐宿主验证。

agent 是另一种作者，与人工使用同样的产物规则；作品完成后可独立运行。实时 AI 参与剧情是另一个需求，当前未提出。

## 7. 工具与作品产物规范（建议）

### 7.1 交付对象与组织

| 对象 | 内容 |
| --- | --- |
| 编辑工具 | 桌面程序、版本、说明、示例工程及 agent 接入说明 |
| 可编辑工程 | 作品内容、素材、流程布局及编辑辅助信息，支持迁移后继续编辑 |
| 运行包 | 从工程生成的运行数据、必需素材、播放器或明确的播放器要求 |
| 读者存档 | 当前页面、路径和变量当前值等，与作品初始定义分离 |

工程内容是唯一编辑来源，导出器生成运行包，不分别手工维护两套剧情。示意结构为 project.json + assets/；运行包为 manifest.json + book.json + assets/，按目标决定是否携带 player/。这些文件名、扩展名及压缩方式未定，开发目录形式可后续打包。

### 7.2 格式契约

| 契约 | 需要明确的信息 |
| --- | --- |
| 身份与版本 | formatVersion、作品 ID、内容版本、所需播放器版本/能力，软件版本与格式版本分开 |
| 页面与流程 | 稳定页面/连接 ID、起点、出口与已支持规则 |
| 图层与素材 | 顺序、可见性、坐标/尺寸单位，素材 ID 与相对路径 |
| 媒体与动画 | 类型、时间单位、播放/停止/重播、效果 ID 和参数 |
| 素材清单 | 类型、编码、尺寸/时长、大小及可选摘要，不依赖作者绝对路径 |
| 状态与条件 | 若采用，声明变量类型、初值、效果、重复触发及回退规则 |
| 兼容 | 未支持的版本/能力明确报告，有记录的迁移，不静默删内容 |

媒体支持清单需描述容器及编码；MP4 不表示任意编码都可播放。PNG/JPEG/WebP、MP3/WAV/M4A、H.264/AAC MP4 只是候选验证样本，未构成兼容承诺。

### 7.3 草稿、校验与发布

未连完的流程可保存为草稿；结构损坏或写入失败不能覆盖有效工程。发布校验应检查版本、唯一 ID、引用、起点、素材和目标能力，区分阻断错误与提示并定位到对象。无可用出口依据终点/兜底规则诊断；无法静态判定的路径记录并做运行验证，不承诺穷举所有条件。

编辑预览和运行包使用同一播放语义，分别核对音画、路径和状态。复制到新目录/目标环境后应不依赖原素材位置、作者缓存或开发服务器。

作品模型、播放核心与目标封装分离，网页、离线程序及播放器文件是候选导出目标，不要求现在选择唯一形式。媒体、加载、输入和存档适配需按目标验证；编辑器采用 Electron 不意味着每部作品都要打包 Electron。MP4/PDF 若以后支持，是会丢失交互的辅助导出，不等价于完整作品。

## 8. 预留空间的边界

| 未来能力 | 现在建议保留 | 不因此提前建设 |
| --- | --- | --- |
| 非线性流程 | 稳定 ID、独立连接集合，不以单 nextPageId 锁死格式 | 完整分支条件 UI、循环语义与自动布局 |
| 隐藏状态 | 播放状态和初始内容分离，规则与渲染边界 | 公式语言、变量编辑器及调试器 |
| 外部 agent | 共用命令、校验与明确结果 | 全部工具、内置聊天或后台 agent |
| 多目标发布 | 核心不绑定 Electron，存储/加载适配边界 | 所有导出器及通用插件框架 |
| 更多媒体/效果 | 素材 ID、类型、相对引用和效果预设参数 | 全格式转码、完整剪辑和复杂时间轴 |
| 格式演进 | 版本、校验、不支持提示及迁移入口 | 所有未来字段或全历史迁移 |

只实现当前确定功能需要的结构，通过有版本的格式演进扩展。方向确认不等于进入 MVP；未知版本不能静默删字段后重存。全局设计与首版范围分离的裁决优先于早期混合规划建议。

## 9. 发展主题与待决策事项

| 发展主题 | 目标 | 启动依据 |
